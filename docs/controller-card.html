ROV CONTROLS

PS5 DualSense / PS4 controller  ·  press OPTIONS to arm, CIRCLE to stop

Standard profile 2 · default

Left stick ↕forward / back
Left stick ↔turn left / right
Right stick ↕up / down
R2 / L2up / down
D-pad ↑ ↓tilt nose up / down

Tank profile 1

Left stick ↕left motor fwd / back
Right stick ↕right motor fwd / back
R2 / L2up / down
D-pad ↑ ↓tilt nose up / down

TRIANGLE switches profile (only while SAFE). Edit or add profiles on the screen with the mouse: SETUP › PROFILES.

Driving

  1. Turn the controller on (PS button). Screen shows it connected.
  2. Let go of the sticks, triggers and D-pad.
  3. Press OPTIONS to ARM. The motors play a tune: touch any control to skip it.
  4. Press CIRCLE to STOP at any time.

Motors stop by themselves if the controller disconnects or goes quiet for 0.5 s; then press OPTIONS again. Keyboard (switch on in SETUP › EXTRAS): WASD drive · Space/Shift up/down · R/F tilt · Enter ARM · Esc STOP.
